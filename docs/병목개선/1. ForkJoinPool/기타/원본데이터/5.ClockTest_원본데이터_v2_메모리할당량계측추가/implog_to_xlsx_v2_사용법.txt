implog_to_xlsx_v2.py 사용법

1. 무엇을 하는 스크립트인가
   1) 프로브(ImproveCpuUtilizationProbe) 콘솔 출력을 저장한 txt에서 IMPLOG 줄만 골라 엑셀로 옮긴다.
   2) IMPLOG가 아닌 줄(표, [계측] 줄, [할당] 줄, 워커 장부, 구간 시각)은 전부 건너뛴다.
   3) 클럭 CSV는 쓰지 않는다. 클럭이 필요하면 clocklog_to_xlsx_v2.py를 따로 돌린다.

2. v1(1.implog_to_xlsx.py)과 다른 점 세 가지
   1) 새 레코드 형식을 읽는다.
      - 말단(leaf)은 시작시각ms가 붙어 14칸, 스캔(scan)은 9칸이다. v1은 13칸·8칸만 받아 새 로그를 하나도 읽지 못했다.
      - 회차별 원값(run)은 16칸이고 v1에는 처리하는 갈래가 아예 없었다.
      - 칸이 짧은 옛 로그(말단 13칸·스캔 8칸·회차 13칸)도 그대로 읽힌다.
   2) 판정에 쓰는 배수 두 열을 넣었다.
      - 최소 분할 기준 배수 : 같은 병렬도에서 가장 작은 분할을 1로 놓았을 때의 배수
      - 직전 분할 대비 배수 : 분할을 한 단계 늘릴 때 평가 1회가 몇 배가 되나
   3) 회차별 원값 시트를 새로 만든다. elapsed·procCPU·CPU 갈래별 값에 더해 할당 바이트 세 열과 총 할당이 들어간다.

3. 필요한 것
   1) 파이썬 3와 openpyxl이다. 없으면 설치한다: py -3 -m pip install openpyxl
   2) 입력은 콘솔 출력 전체를 저장한 txt 하나다.

4. 실행 명령
   py -3 "implog_to_xlsx_v2.py" "콘솔로그경로.txt" -o "출력.xlsx"
   출력 경로를 생략하면 입력과 같은 자리에 같은 이름의 .xlsx를 만든다.

   예:
   cd "E:\devSpace\SpringBootProjects\ExerciseManagement\docs\병목개선\ForkJoinPool\기타\원본데이터\5.ClockTest_원본데이터_v2_메모리할당량계측추가"
   py -3 "implog_to_xlsx_v2.py" "할당측정_15점스윕_원본데이터_for문전환_ConsoleLog.txt" -o "할당측정_15점스윕_정리_for문전환.xlsx"

5. 만드는 시트
   1) 평가 한 번에 걸린 시간 : 판정에 쓰는 시트다. 분할별 평가 1회당 루프 시간과 배수 두 열이 여기 있다.
   2) 시간이 어디에 쌓였나   : 루프 시간이 합 편차 계산·분포 편차 계산·나머지 어디에 쌓이나. 복사는 얼마인가.
   3) 회차별 원값           : 측정 회차 하나하나의 원값과 할당 바이트.
   4) 그래프 시트 다섯 장    : 평가 1회당 루프 시간, 최소 분할 기준 배수, 루프 시간 총합, sumDev 1회당, distDev 1회당.
   5) leaf 원본 / scan 원본  : 무가공 원본. 분할 36 한 점만 해도 말단이 8,100건이라 15점 스윕이면 행이 매우 많다.

6. 판정에서 볼 것
   1) '평가 한 번에 걸린 시간' 시트의 직전 분할 대비 배수를 분할 1부터 6까지 본다.
   2) 스트림판에서는 이 값이 매 단계 약 1.2배였다. for판에서 이 배수가 사라지거나 크게 줄었는지가 판정 대상이다.
   3) 판 사이의 절대값은 비교하지 않는다. 계측 조건이 다르기 때문이고, 비교는 각 판 안의 배수끼리 한다.

7. 주의할 점
   1) 경로에 한글과 공백이 있으므로 항상 따옴표로 감싼다.
   2) 같은 이름의 엑셀이 열려 있으면 저장이 거부된다. 닫고 다시 실행한다.
   3) 형식이 맞지 않아 건너뛴 줄이 있으면 실행 끝에 줄 번호와 함께 출력된다. 그 건수가 0인지 확인한다.
   4) 콘솔 출력이 길어 IntelliJ 콘솔 버퍼를 넘길 수 있다. 버퍼를 늘리거나 실행 출력을 파일로 받는다.
