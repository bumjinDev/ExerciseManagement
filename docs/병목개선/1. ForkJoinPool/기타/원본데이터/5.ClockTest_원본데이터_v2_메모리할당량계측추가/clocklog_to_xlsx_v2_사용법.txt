clocklog_to_xlsx_v2.py 사용법

1. v1과 무엇이 다른가
   1) 프로브 IMPLOG run 레코드 끝에 붙는 할당 바이트 세 칸(main할당B, 워커할당B, 기타할당B)을 읽는다.
   2) '회차별 측정값' 시트에 열 여섯 개가 늘어난다.
      - main 할당(MB), 워커 할당(MB), 기타 할당(MB), 총 할당(MB), 평가 횟수(회), 평가 1회당 할당(B)
      - 총 할당 = 세 갈래의 합. 평가 1회당 할당 = 총 할당 ÷ 평가 횟수.
      - 평가 횟수는 IMPLOG leaf의 sumDev 실행 횟수 합이라 회차마다 정확하다.
      - 순차 행은 말단 기록이 없어 평가 횟수와 평가 1회당 할당이 빈 칸이다. 할당 세 열은 채워진다.
      - MB는 1,000,000바이트 기준이다.
   3) 할당 세 칸이 없는 옛 로그도 그대로 읽힌다. 그때는 할당 열만 빈 칸이고 콘솔에 알림이 한 줄 뜬다.
   4) 나머지 시트(클럭 정리, 구간과 스레드 매핑, 스레드별 클럭, 차트, 차트 데이터)와 계산은 v1과 같다.

2. 필요한 것
   1) 파이썬 3와 openpyxl이다. 없으면 설치한다: py -3 -m pip install openpyxl
   2) 입력 파일 두 개다. 클럭 CSV와 콘솔 로그 전체를 저장한 txt다.

3. 실행 명령
   py -3 "clocklog_to_xlsx_v2.py" "클럭CSV경로" "콘솔로그경로" -o "출력.xlsx"

   예:
   cd "E:\devSpace\SpringBootProjects\ExerciseManagement\docs\병목개선\ForkJoinPool\기타\원본데이터\5.ClockTest_원본데이터_v2_메모리할당량계측추가"
   py -3 "clocklog_to_xlsx_v2.py" "할당측정_분할36_원본데이터.csv" "할당측정_분할36_원본데이터_ConsoleLog.txt" -o "할당측정_분할36_정리.xlsx"

4. 옵션
   --base 숫자 : 기본 클럭 GHz. 기본값은 2.69다. 엑셀 안에서도 클럭 정리 시트의 B2 칸을 고치면 다시 계산된다.

5. 확인할 것
   1) 총 할당(MB)이 회차마다 비슷한가. 같은 일을 5번 한 것이므로 크게 흔들리면 안 된다.
   2) 평가 1회당 할당(B)이 관찰 문서의 10,839바이트 근처인가.
   3) 분할 개수를 여러 점 재면 설정이 달라도 총 할당이 같은가. 할당량은 분할과 무관하므로 같아야 맞다.
   4) 순차 행의 총 할당이 병렬 행과 비슷한가. 일의 양이 같으므로 크게 다르면 안 된다.

6. 주의할 점
   1) 경로에 한글과 공백이 있으므로 항상 따옴표로 감싼다.
   2) 같은 이름의 엑셀이 열려 있으면 저장이 거부된다. 닫고 다시 실행한다.
   3) 자정을 넘긴 측정은 지원하지 않는다.
