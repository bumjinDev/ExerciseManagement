clocklog_to_xlsx.py 사용법

1. 무엇을 하는 스크립트인가
   1) typeperf가 남긴 클럭 CSV와 프로브 콘솔 로그(txt)를 읽어 엑셀 하나를 만든다.
   2) 시트는 네 장이다.
      - 클럭 정리 : 표본별 클럭. 논리 프로세서 숫자순.
      - 구간과 스레드 매핑 : 구간(순차/워밍업/측정 회차/워커 CPU 읽기)별 시각 경계·실행 스레드·평균 클럭.
      - 스레드별 클럭 : 측정 회차 안의 스레드(워커·main) 하나하나의 활동 창과 그 창의 클럭.
        아래에 풀·main별 클럭 표본 매핑 표가 있다. 행 하나가 (풀 또는 main, 그 활동 창에 걸린 클럭 표본 1개)다.
        주의: 클럭 값은 전체 프로세서 평균이다. 스레드가 어느 프로세서에서 돌았는지는 기록되지 않아 특정 코어의 클럭이 아니다.
      - 차트 : 전체 평균 추이 선 그래프와 구간별 막대 그래프.
   3) 구간 경계는 콘솔 로그의 [구간 시각] 줄과 IMPLOG의 시작시각ms에서 읽는다. 둘 다 있는 로그여야 한다(2026-08-03 수정판 이후).

2. 필요한 것
   1) 파이썬 3와 openpyxl이다. 없으면 설치한다: py -3 -m pip install openpyxl
   2) 입력 파일 두 개다. 클럭 CSV와 콘솔 로그 전체를 저장한 txt다.

3. 실행 명령
   py -3 "clocklog_to_xlsx.py" "클럭CSV경로" "콘솔로그경로" -o "출력.xlsx"

   이번 분할 1 파일로 실행하는 예:
   cd "E:\devSpace\SpringBootProjects\ExerciseManagement\docs\병목개선\ForkJoinPool\기타\원본데이터\4.ClockTest_원본데이터"
   py -3 "clocklog_to_xlsx.py" "병렬도6과12_말단작업분할수준_1_원본데이터_2.csv" "병렬도6과12_말단작업분할수준_1_원본데이터_2_ConsoleLog.txt" -o "병렬도6과12_말단작업분할수준_1_클럭정리.xlsx"

4. 옵션
   1) --base 숫자 : 기본 클럭 GHz. 기본값은 2.69다(작업 관리자 성능 탭의 기본 속도).
      엑셀 안에서도 클럭 정리 시트의 B2 칸을 고치면 GHz가 다시 계산된다.

5. 주의할 점
   1) 경로에 한글과 공백이 있으므로 항상 따옴표로 감싼다.
   2) 실행이 끝나면 콘솔에 구간 목록이 찍힌다. 구간 개수와 시각이 콘솔 로그와 맞는지 여기서 한 번 확인한다.
   3) 평균 클럭 열은 수식이라 엑셀에서 열 때 계산된다. 값이 비어 보이면 F9로 다시 계산한다.
   4) epoch ms를 지역 시각으로 옮기는 시간대 편차는 로그 자체에서 자동으로 계산하므로 어느 기계에서 돌려도 된다. 자정을 넘긴 측정은 지원하지 않는다.
   5) 분할 개수와 병렬도가 몇 개든 같은 스크립트로 된다. 콘솔 로그에 있는 설정을 전부 구간으로 만든다.
