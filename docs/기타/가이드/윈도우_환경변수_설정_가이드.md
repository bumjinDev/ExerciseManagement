# 윈도우 환경변수 설정 가이드 (JWT_SECRET_KEY · DB_PASSWORD)

작성일: 2026-07-07
대상: 로컬 Windows 11 개발 환경 (단계 2 회원 관리 기능 실행 전제)

애플리케이션은 아래 두 값을 소스나 설정 파일에 하드코딩하지 않고 환경 변수로만 읽는다.

| 변수명 | 용도 | 값 |
|--------|------|-----|
| `JWT_SECRET_KEY` | JWT 서명 키 (HMAC-SHA256) | Base64 인코딩된 32바이트 난수 (아래 1번으로 생성) |
| `DB_PASSWORD` | Oracle EXERCISEMGMT 계정 비밀번호 | 단계 1에서 계정 생성 시 정한 값 |

---

## 1. JWT_SECRET_KEY 값 생성

PowerShell을 열고 아래를 실행한다 (Windows PowerShell 5.1 기본 탑재 기준):

```powershell
$b = New-Object byte[] 32
(New-Object System.Security.Cryptography.RNGCryptoServiceProvider).GetBytes($b)
[Convert]::ToBase64String($b)
```

출력되는 44자 내외의 Base64 문자열(예: `Qm3x...=`)이 `JWT_SECRET_KEY` 값이다. 복사해 둔다.
키는 한 번 생성해서 계속 사용하면 된다. 키를 바꾸면 기존에 발급된 JWT 쿠키는 전부 무효가 된다.

---

## 2. 환경 변수 등록 (세 방법 중 하나 선택)

### 방법 A. 시스템 환경 변수 GUI — 권장 (터미널·IDE 실행 모두 적용)

1. `Win + R` → `sysdm.cpl` 입력 → 확인
2. **고급** 탭 → **환경 변수** 버튼
3. 상단 "사용자 변수" 영역에서 **새로 만들기**:
   - 변수 이름: `JWT_SECRET_KEY` / 변수 값: 1번에서 생성한 Base64 값
   - 변수 이름: `DB_PASSWORD` / 변수 값: EXERCISEMGMT 비밀번호
4. 확인으로 모두 닫는다.
5. **열려 있는 터미널과 IDE(IntelliJ/Eclipse)를 완전히 종료 후 다시 실행**해야 반영된다.

### 방법 B. setx 명령 (사용자 환경 변수 영구 등록, GUI와 동일 효과)

PowerShell 또는 cmd에서:

```powershell
setx JWT_SECRET_KEY "<Base64 값>"
setx DB_PASSWORD "<비밀번호>"
```

주의: `setx`는 **현재 창에는 적용되지 않는다.** 새로 여는 터미널부터 유효하며, IDE도 재시작해야 한다.

### 방법 C. 현재 세션 한정 (일회성 테스트 실행용)

영구 등록 없이 지금 열려 있는 PowerShell 창에서만 쓰려면:

```powershell
$env:JWT_SECRET_KEY = "<Base64 값>"
$env:DB_PASSWORD    = "<비밀번호>"
.\gradlew.bat bootRun
```

같은 창에서 서버를 실행해야 적용된다. 창을 닫으면 사라진다.

### IDE에서 서버를 실행하는 경우

방법 A/B 대신 실행 구성에 직접 지정할 수도 있다:

- **IntelliJ**: Run → Edit Configurations → 해당 Spring Boot 구성 → Environment variables 칸에
  `JWT_SECRET_KEY=<값>;DB_PASSWORD=<값>`
- **Eclipse/STS**: Run → Run Configurations → 해당 구성 → **Environment** 탭 → Add

---

## 3. 등록 확인

새 PowerShell 창에서:

```powershell
$env:JWT_SECRET_KEY
$env:DB_PASSWORD
```

cmd라면:

```cmd
echo %JWT_SECRET_KEY%
echo %DB_PASSWORD%
```

값이 출력되면 정상이다.

---

## 4. 서버 기동

```powershell
cd E:\devSpace\SpringBootProjects\ExerciseManagement
.\gradlew.bat bootRun
```

정상 기동 시 로그 마지막에 다음이 보인다:

```
Tomcat started on port 8186 (http) with context path '/exercise'
```

- `JWT_SECRET_KEY 환경 변수가 설정되지 않았습니다` 오류 → 1~2번 재확인 (터미널/IDE 재시작 여부 포함)
- `ORA-01017: invalid username/password` → `DB_PASSWORD` 값 재확인
- 기동 후 API 테스트는 `docs/테스트/회원관리_Postman_테스트_명세서.md` 를 따른다.
